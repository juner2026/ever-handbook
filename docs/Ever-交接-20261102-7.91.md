## 一、这一版改的三条

### ① 点全屏黑一段时间

黑的是「桌面 iframe 按新视口重排」那一帧。这一版双保险：

1. 进/退全屏**之前**就盖米色遮罩（挂在珍珠 `pointerdown` + `requestFullscreen` 包装里，不等事件回来）；
2. 遮罩期间把重排**冻住 1.2 秒**（复用 7.82 的 `__teKbHoldUntil` 闸门，`layout()/relayout()/check()` 都会让路）；
3. 遮罩撤掉前（950ms）在后台补一次 `__jhRelayout()`，保证尺寸正确再露脸；
4. 遮罩 1150ms 后再淡出。

### ② 工具调用没显示在思考链里

之前只在**历史重进**那条渲染路径（L17434）给 `.thought-wrap` 挂了 `data-tools`；
**实时回复**走的是另一条路径（L19662 的 `tpId`），根本没有数据 —— 所以"依旧没显示"。

现在 `tpToggle()` 里加了兜底：没有 `data-tools` 时，顺着思考块往后找那条 `.tool-call` 块，
把里面的条目读出来当时间轴（有 `ms` 才显示秒数）。

实测（模拟实时路径：只有思考块 + 消息 + 工具条，无 data-tools）：

```
● 调用 MCP · filesystem | read_file
● 发送动态 · 发了一条动态
```

### ③ 米色主题下用户气泡不是白色

之前「主题色 24% + 白 78%」，米色主题下整体偏米。改成**白为主**：
白 92% + 主题色 10%。实测灰/米主题下气泡 = `color(srgb .99 .94 .96 / .93)`（接近纯白），
粉色主题下仍是极淡粉。
