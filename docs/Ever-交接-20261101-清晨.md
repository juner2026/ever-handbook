## 4. 这次踩的坑（下次别重复）

1. **应用抽屉是懒创建的**：`#jhApps` 要点一次 `.topbar .mk` 才有；测试脚本先开抽屉再取 `.jh-tile`。
2. **`send()` 只发不收**：发完要点爱心 / 调 `aiReplyNow()` 才会真的去请求 AI（否则永远没有回复）。
3. **星露谷在外壳**：走 `window.__svOpenTop()` → `#svTopFrame`；文档里的 `#svFrame` 是 0×0 的旧壳。
   而且游戏 frame 的 URL 是百分号编码，匹配要用 `decodeURIComponent`。
4. **应用的返回键**统一是界面左上 `.jwh-back`（‹），不是 Escape。
5. **版本串在外壳页脚**，`document.body.innerText` 在桌面 iframe 里搜不到，别慌。
6. **排版开关**在 `classic/scrapbook` ↔ `collage/editorial` 两态之间切；测同一个页面要各自开新页。
7. **`bash` 里 echo 带反引号的 markdown 会被当命令替换**（这次真把一段说明吃掉了）——写文档用 python。
8. 明信片链路日志前缀是 `MDIAG`，直接看 console 就能判断"卡在哪一道闸"。
9. 无头 Chromium 里 16 MB 单文件 `DOMContentLoaded ≈ 3.5 s`，别把它当成真机数值。
