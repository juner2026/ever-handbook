## 7. 这轮的坑（别重复）

1. **设置页旧结构已整段删除**：`.set-menu / .set-row / .set-hero / .set-top / .set-footer / #buildTag` 都没了。
   `addSetPageRows()`、`buildLegacy()`、`removeBeautyRow()` 现在查不到 `.set-menu`，自动空转（不报错，留着没坏处）。
2. **`#p-set *{font-size:13px!important}` 会压死新样式** → 新页面所有字号都带 `!important`（`apply.py` 的 `force_important()` 自动补，逐条声明）。
3. **搜索隐藏不能写行内 `style="display:none"`**：`.st2-tile{display:flex!important}` 会压过行内样式。
   要用类 + `!important`（`.st2-off.st2-off`），`filter()` 里统一走 `setOff()`。
4. **自定义属性 `--x` 不能补 `!important`**（值会被污染），`force_important()` 已跳过。
5. **设置页壁纸要 4 个 `#p-set` 提权**（`#p-set#p-set#p-set#p-set .set-bg`）才压得开 7.77 的 `display:none!important`。
6. **`#p-set` 里的 sticky 页头**别再叠半透明渐变：内容会从渐变底下透出来像鬼影，现在是实底 + 1px 投影。
