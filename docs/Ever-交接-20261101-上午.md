## 4. 这次踩的坑（下次别重复）

1. **悄悄话页是 JS 重建的**：`buildWhisperNew()`（页面加载 650ms 后）会把 `#p-whisper` 的
   `innerHTML` 换成 `WH_HTML` 字符串。**只改静态 HTML 没用**，两处都要改，否则你会对着旧界面发呆。
2. **这个文件是 `!important` 战场**：旧规则写成 `html body #p-whisper #whBox #whBody .wh-msg-bubble{…!important}`
   （3 个 id）。新样式要压过它们，选择器得用 `html body #p-whisper#p-whisper#p-whisper …`
   （同一个 id 重复写算多次权重）+ 每条声明也带 `!important`。
3. **批量加 `!important` 会踩两个坑**：① 一条声明被拆行时丢了结尾 `;` → 整条规则失效（表现是"样式忽好忽坏"）；
   ② 以逗号结尾的选择器续行被当成声明处理 → 规则直接作废。
4. **右上角的珍珠 `#everFsPearl`** 是 `position:fixed` 压在最上层的，会挡住页头右侧的字。
   本轮用 `body:has(#p-whisper.on) #everFsPearl{display:none}` 在两页藏掉。
5. **`dressWhisper()`** 会往 `.wh-conv` 里塞占位块、往 `.cset-title` 里写标题；新结构刻意**避开了这些类名**
   （对话区叫 `.wh-room`、标题行叫 `.wh-top`），否则会多出一块怪东西。
6. 小游戏的调试行是 `gmDbg()` 直接写进 `.gm-addr` 的，**删地址栏之前先把 gmDbg 改成只 log**，否则报错。
7. `#gmMain .gm-tip{display:none!important}` 被旧版藏过（两处），想要提示行必须显式 `display:block!important`。
8. 无头里 16 MB 单文件 `load ≈ 4 s`，别把它当手机实测值。
9. **`<input type=file>` 别用 `hidden`/`display:none`**：Android WebView 里经常点了没反应。
   一律"临时建、挂到 body、`left:-9999px`、选完 remove"（`pickAva` / `gmMiniPick` / 新的 `stkPickFile` 都这么写）。
   测这个用 Playwright 的 `filechooser` 事件，能真验"点一下会不会弹选择器"。
10. 表情包模块的 `_stk` 是 IIFE 私有变量，测试别想直接改；用 `stkOpen()` + `localStorage['stk_data']` + `stkEdit()`（有挂在 window 上）。
