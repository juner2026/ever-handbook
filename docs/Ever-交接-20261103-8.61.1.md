## 0. 一句话现状
手机上“进不去 / 开屏动画不播 / 一直白屏”两个根因都修了：① `#jh-home` 用 JS 量尺寸那条老路（8.10 未收口）；② **`v.txt` 没 bump，SW 一直吐旧缓存**。
---
## 1. 根因两条
### ① 盒子被量歪（round-812）
8.10 交接条里写“没有收口”。按它给的兜底路线做：`s≈1 && fit≈1`（手机必然）时给 `<html>` 挂 `.jh-plain`，
`#jh-home` 用 CSS `!important` 直接铺满视口，不再写 `width/height/left/top/transform`。`?plain=0` 可关掉做对照。
### ② 版本探针没动，SW 缓存优先 → 白屏根因
`sw.js` 是“缓存优先 + 只查 `v.txt` 比版本”。推了新的 `ever.html` 但 `v.txt` 仍是 `8.60.1`，
于是 SW 认为没新版本，继续吐缓存里那张旧的跳转页 / 旧的 17MB——脸上就是“纸色卡住不动”。
**以后每次发版必须同时改三处**：`v.txt`、`sw.js` 的 `BUILD`（必须等于 v.txt）、`sw.js` 的 `VER`（换缓存桶清旧缓存）。

## 3. 怎么发版（手机上的实际流程）
```bash
# 1) 改源码 _mobile/src/*
python3 _mobile/build.py            # 约 4分30秒，产出 _mobile/out/ever-mobile.html
# 2) 改 v.txt 版本号 + sw.js 的 BUILD / VER
# 3) github.com 直连不通，走 api.github.com 的 Contents API 推送（token 在 mcp_config.json）
```
`github.com` 的 `git clone/push` 在这条网络上会被 TLS 挫断（GnuTLS recv error -110），
但 `api.github.com` / `raw.githubusercontent.com` / `codeload.github.com` / `*.github.io` 都通。
整个仓库可用 `https://codeload.github.com/juner2026/ever-handbook/tar.gz/refs/heads/main` 11 秒拉完（79MB）。
