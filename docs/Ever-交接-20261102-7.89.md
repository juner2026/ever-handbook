## 这版做的事：把家园那套改动**退干净**，只留不碰布局的修复

用户反馈：改完家园之后「整页动不动就弹一下」「家园聊天窗拖不动」。
7.85 / 7.86 / 7.87 三版都是围绕「家园强制横屏 + 退家园」做的，已全部 `--revert`。

**弹动的来源**（判断）：7.85 把 `#teHome4` 用 `rotate(90deg)` + 改宽高铺满，
退出时再把这些内联尺寸/旋转清掉。这层是 fixed 全屏容器，它和 App 的缩放层（`--z`）
互相打架，任何一次 reflow 都会让整页重新算一次位置 → 看起来"处处弹"。
叠上 7.86 的 `.te-no-fx *{animation:none}`（600ms 后撤，动画一起从第 0 帧重开）就更明显。

### 留在这一版里的（都不碰家园布局）

| # | 内容 | 说明 |
| --- | --- | --- |
| ① | `teHomeLeave` 不再 `exitFullscreen` / `orientation.unlock` | 「点返回莫名其妙退全屏」的真正原因，删掉就行，和布局无关 |
| ② | 图片 `min-width/min-height:96px` | 占位规则是 140×72，加载完缩回 96 → "时大时小" |
| ③ | 用户气泡 = 主题色 24% + 白 78% | 白主题 = 白气泡；粉主题 = 淡粉 |
| ④ | 进全屏**之前**先盖米色遮罩 | 挂在 `requestFullscreen` 调用前 + 珍珠 pointerdown，620ms 后淡出 |
| ⑤ | 思考链里的工具调用时间轴 | 竖线+圆点+条目，有耗时（MCP 的 `ms`）才显示秒数，在思考正文上方 |

### 这一版**没有**做的

- **家园强制横屏**：回滚了。它是"整体弹动"的源头。要横屏得换思路（比如只转家园内部的
  iframe 内容，不转这层 fixed 容器），而且要真机逐步验证。

实测（headless）：
- 进家园后 `#teHome4` 的 `transform` 为空（不再旋转）
- 退家园前后 `fullscreenElement` 都是 false、`#jh-home` 一直是 `display:block`
