## 3. 工作方式（照这个来，别重复踩）

### 构建 / 验证

```bash
cd /sdcard/Download/WeiXin
python3 /tmp/apply2.py                 # 从 shell.html.bak-before-stage02 重建全部改动（幂等检查）
python3 _mobile/build.py --no-inline   # 0.3s，快迭代
python3 _mobile/build.py --install     # 2min，出 ever.html + 孪生（自动备份）
node _mobile/smoke.cjs /sdcard/Download/WeiXin/ever.html   # 必须绝对路径！
```

- **PARITY 必做**：`build.py` 后比 `_mobile/out/ever-mobile.html` 与 `ever.html`，归一化 `__everVer` 后应相等。
- **pageerror 必看**：这一轮踩过"删数组把脚本改坏"，`Unexpected token ':'` 会让整段脚本静默不跑。
  用 Playwright 打开后打印 `pageerror`，别只看截图。
- 预览地址用 **`http://<hostname -I>:8901/...`**，`127.0.0.1` 手机连不上。

### 踩过的坑（别重复）

1. **批量脱敏/截断要跑 pageerror**：我为了开源"保险"把 MCP remote 段整段删掉，
   结果把后面 `<script>` 弄成语法错误，7.73–7.75 三版带病上架。
2. **`!important` 战场**：旧规则动辄 `html body #p-xxx #whBox #whBody ...{!important}`。
   新样式要 `html body #p-set#p-set#p-set ...` + 每条声明 `!important`（`apply2.py` 的 `boost()` 已自动化）。
3. **批量加 `!important` 的坑**：一行声明没结尾 `;` → 整条规则失效；逗号续行被当声明 → 规则作废。
4. **悄悄话页是 JS 重建的**：`buildWhisperNew()` 650ms 后把 `#p-whisper` 的 innerHTML 换成 `WH_HTML`，
   只改静态 HTML 没用。
5. **`<input type=file>` 别用 `hidden`**：Android WebView 常不弹选择器。一律"临时建、挂 body、`left:-9999px`、选完 remove"。
   （`pickAva()` / `gmMiniPick()` / `stkPickFile()` / 聊天壁纸都这么写）
6. **拍一拍/打赏是 `role:'system'` 旁白**，会进提示词 → 旧名字会出现在思考链里。
   改名时要把历史里的旁白一起迁移（`tePatNameFix`），但**别重排方向**。
7. **无头里 17MB 单文件 `load ≈ 4–5s`**，别当手机实测值。
