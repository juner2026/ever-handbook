## 2. 这一版做了什么（按时间顺序，含已撤销的）

### 2.1 已落地

1. **手机自动识别**：宽 < 560 自动 `data-mh="phone"`（原来这值靠打包写死，手机上一直按平板缩放出"整本转 90°"的怪样）。顶栏「手机/平板」胶囊仍可用，用户手动切过就听用户的（`te-journal-layout`）。只加了 `window.__jhGo` / `__jhForce` / `__jhPagesRefresh` 三个钩子。
2. **真全屏**：`100dvh` + `env(safe-area-inset-*)` + `overscroll-behavior:none`；手机顶栏收成一行（品牌 + 6 色点），`viewchip / mhchip / sizebox / 应用APPS 胶囊` 在手机上隐藏。
3. **侧边栏第 4 枚书签「应用」**：沿用 `.ribbon button` 原样式，插在「设置」前面。
4. **应用页 `#pg-apps`**（新页，`.page` 体系）：抬头 + 25 个 `.cell2`（图标 64 格线稿 + 手写英文 + 宋体中文），装在同一套 `.sheet` 纸里。
   - **手机 5 列 × 5 行、平板 7 列 × 4 行，一屏装完、不上下翻**（`overflow:hidden` + `grid-auto-rows:min-content` + `align-content:space-evenly`）
   - 图标 32px（平板 42）、行距均匀、页脚写版本号
5. **应用页那张纸的精修**：左上金胶带、右上粉胶带、左缘 4 枚装订孔、内层金线（虚线里再收一道）、左下书牌 `APPS · No.25`、右下折角、标题下手绘波浪线（`.hand-hr`，原本被 `html .hand-hr{display:none!important}` 关着，只在这一页放开）、底纸横线纹理 + 页边虚线 + 水彩晕 + `feTurbulence` 纸纤维（纸面中心实测 rgb(247,243,240)，是暖象牙白不是粉色）。
6. **第一页「Us」那张大片**：从空拍立得改成**小相机**（172px 纸卡 + 取景器 + 红色快门点 + 镜筒三环 + 底唇 `Us / INSTANT FILM · 1/1`，换图钮 ⟳ 挪到机身右上）。
7. **相机左右两枚像素贴图**：左 `melody2`（手柄）、右 `melody3`（音符），已用 `saturate(.52) brightness(1.07)` + `opacity .82` 调淡成灰粉。
8. **MCP 那一格**：右上角一颗金色小星星（纯 CSS/SVG data-URI，3.6s 呼吸，`prefers-reduced-motion` 下不动）；右侧空白处 62px 像素猫脸 `melody8`。
9. **可编辑气泡框**：相机上方那条空白带里，`contenteditable`，Caveat 16px，尾巴朝下指相机；边打字边存 `localStorage.m2_bubble`（实测重载保留），回车失焦不换行，空时显示「点这里写字」。
10. **相册 / 画廊相框**：白边更明确、相片窗口凹进去（内描边 + 内影）、底唇编号（相册 `No.01-03`、拱门 `·I·II·III`）；**相片位保持空白，留给用户自己放图**。
11. **`manifest.webmanifest`**：`orientation` landscape → **portrait**（原来"添加到主屏幕"会强制横屏）。
12. **`_传手机.py`**：平板→手机的局域网传输服务（绑 `0.0.0.0`，带下载按钮、no-store、X-Ever-Lan 头）。
13. **`build.py` 图片内联**：把 `aset/` 下 42 张图（3 MB）内联成 data URI —— 这样"只拷一个 html"到手机也不掉图（珍珠、书皮、唱片、头像都在）。`--no-inline` 可关。

## 4. 源码结构与怎么改（关键）

`ever.html` 是「外壳 + 一段 1.1 MB 转义桌面文档（`window.__JH_DOC`）」拼成的单文件。
**不要直接改 7.5 MB 单文件**，改拆分后的明文源码：

| 文件 | 说明 | 行数 |
| --- | --- | --- |
| `_mobile/src/shell.html` | 外壳（桌面文档位置留 `__JH_DOC_PLACEHOLDER__`） | — |
| `_mobile/src/jh-doc.html` | 桌面文档明文 | 9,207 |
| `_mobile/src/patch/m2-apps.css` | 本轮所有样式（手机端 + 应用页 + 拍立得 + 气泡 + 星星/猫） | 457 |
| `_mobile/src/patch/m2-apps.js` | 本轮所有行为（手机识别 + 应用页 + 25 图标 + 气泡 + 拍立得填图函数已删） | 327 |
| `_mobile/build.py` | 拼装 + 图片内联 + 逐字符自检 + 落地 | — |
| `_mobile/shot.cjs` `shotdoc.cjs` `shotscroll.cjs` `probe.cjs` | 截图/量尺寸的小工具（Playwright + 自带 chromium） | — |
| `_传手机.py` | 平板 → 手机 局域网传输 | — |

```bash
python3 _mobile/build.py            # 只产出 _mobile/out/ever-mobile.html
python3 _mobile/build.py --install  # 覆盖 ever.html + TidalEcho-手帐桌面.html（自动 .bak）
S=/sdcard/Download/WeiXin/ever.html node _mobile/shot.cjs out.png 393 852 '?splash=off' --page
```

`build.py` 每次都会：剥掉上次注入的 `<!--M2-INJECT-BEGIN/END-->` → 插入新补丁 → 内联图片 → **把产出再解析一遍逐字符比对桌面文档** → 不一致就报错不落地。

桌面文档里只打了 4 个补丁（都只有几行）：

| 位置 | 加了什么 |
| --- | --- |
| `jh-doc.html` ~5945 | `NAMES` 里加 `'pg-apps':'应用'` |
| ~5948 | `window.__jhPagesRefresh`（页是后插的，要能重新取一遍 `pages/tabs`）|
| ~5966 | `window.__jhGo = go;` |
| ~5967 | `window.__jhForce = function(id){ current=''; go(id); };`（父页面直接改 `.page.on` 之后 `current` 会失同步，不强制就点不动——这个坑用户实测踩到过）|

## 7. 已知问题 / 待观察

1. **平板 IP 会变**：今天从 `192.168.10.210` 变成 `192.168.10.48`，导致用户手机报"无法打开页面"。
   平板上「设置 → WLAN → 当前网络」可查；服务重启用 `python3 _传手机.py 8901`。
2. **`file://` 打开存不了数据**（浏览器限制 localStorage/IndexedDB）→ 要存数据就用 `http://…:8901` 这个地址，两个源不互通。
3. **`aset/*.html` 不内联**（`diary/book.html` 日记本、`home4/editor.html` 家园编辑器）—— 单文件拷走后这两个功能会 404，其余正常。
4. **平板打开应用页**的样子没作为验收项（用户说平板不用管），5 列版实测能一屏放下。
5. **气泡框位置是妥协**：那条空白带只有 ~36px，文案一长会压到相机顶部的胶带。可选项：把相机卡从 172 缩到 150，右边腾位置；或气泡改竖排贴相机右侧（音乐符上方）。
