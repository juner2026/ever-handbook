## 一、逐条改动

### ① 思考链里显示工具调用（实时回复那条路径）

7.91 的做法是"点开思考链时，顺着兄弟节点找 `.tool-call`"。实际用起来找不到 ——
工具条可能是后插的、可能包在 `.bbl` 里、兄弟超过 6 个就放弃。

现在改成**渲染时就挂**：

- `chatSend()` 插入 `thoughtHtml(tpId)` 之后记下 `window.__liveTpId = tpId`；
- `_toolCallsHtml(calls)` 每次被调用，就把这批调用**合并**进那个思考块的 `data-tools`
  （去重、多轮累加，不覆盖）；
- `_chatReplyDone()` 里清掉 `__liveTpId`，不会串到下一轮；
- 行文字改成「类型 · 内容」，行首带工具名。

实测（模拟实时路径：只有思考块 + 消息 + 工具条，没有预置 `data-tools`）：

```
● 调用 MCP · filesystem | read_file
● 发送动态 · 发了一条动态
```

历史重进那条路径本来就挂 `data-tools`，不受影响。

### ② 用户气泡 = AI 气泡（半透明）

先量了计算样式：

| | background | backdrop | 圆角 | 阴影 |
| --- | --- | --- | --- | --- |
| AI（改前） | `rgba(255,255,255,.44)` | `blur(.6px) saturate(1.1)` | 16px | `rgba(120,70,96,.75) 0 10px 26px -22px` |
| 用户（改前） | `color(srgb .99 .94 .96 / .93)` ← **基本不透明** | `blur(7px) saturate(1.15)` | 16px | 4 层 inset 描边 |
| 用户（改后） | `rgba(255,255,255,.44)` | `blur(.6px) saturate(1.1)` | 16px | 同 AI |

选择器必须用 `html body #p-chat#p-chat#p-chat #chatBody .msg.me .bbl`（和 7.85/7.87/7.91
那几条同权重），否则会被打回去 —— 那几条是历史遗留，这次没有删，只是用后面的同权重规则盖住。
群聊容器 `#gcMsgs` 也一并写了。

### ③ 设置页顶栏真磨砂

`.st2-nav` 原来是 `background:#fbf8f5!important`（**不透明**），所以
`backdrop-filter:blur(16px)` 一直是个摆设。改成：

```css
html body #p-set .st2-nav{background:rgba(251,248,245,.62)!important;}
html body.te-night #p-set .st2-nav{background:rgba(22,18,19,.62)!important;}
```

夜间那套同理（原来也是 `#161213` 不透明）。

### ④ 页面弹动：`layout()` 每 100~200ms 重写一次全屏 iframe

用 MutationObserver 盯 `#jh-home` 的 style，实测**空闲时也在不停写**（同一组值反复写）：
来源是 `layout()` 被开屏看护 / resize / 600ms 轮询连着叫，每写一次还会跑 `calibrate()` ——
`calibrate()` 把盒子改成小数像素（`Math.round(W/kx*100)/100`），下一次 `layout()` 又整回整数，
于是整块 13 万行的桌面就在"整数像素 ↔ 小数像素"之间来回抖。

改法：

1. `layout()` 先算签名 `left|top|w|h|transform`，和上次一样就 **return**（不写样式、不 calibrate、不 snapDesk）；
2. `calibrate()` 的结果因此能留住，不再被下一次 layout 打回原形；
3. `relayoutDesk()` 以前**无条件**往桌面 iframe 里 `dispatchEvent('resize')` ——
   那本桌面每次都会整本重新排版。现在只有盒子尺寸真的变了才发。

实测（改后）：空闲 2s 内 `#jh-home` 的 style 写入 **0 次**；点一下桌面 **0 次**；点右侧栏 **0 次**
（改前每次都是 4~12 次，并伴随一次桌面整本重排）。

## 四、没做的 & 需要拍板的

1. **全屏珍珠黑一阵**：这条 HTML 层面盖不住。`requestFullscreen` 会重建窗口，
   露出屏幕那 1~2 帧是系统合成器的黑，网页里的遮罩只能盖网页自己的画面。
   两条路，得用户选：
   - **(a) 保留真全屏**（现在就是），接受那一下；
   - **(b) 彻底不调 `requestFullscreen`**，改成"App 内沉浸"：隐藏 App 自己的栏，
     但浏览器/WebView 自己的状态栏还在 —— 不会再黑，但也不是真全屏。
2. **"每点一下都弹动"** 这版已经拿掉了实测到的抖动源（`layout()` 反复重写）。
   如果真机上还有，需要用户给一个具体动作（点哪个页面的哪个位置、第几次），
   或者录个屏 —— 无头里点按本身量不到任何几何变化。
3. 设置页顶栏之外，**其它页面的顶栏**（聊天页、日记页）还是各自的老样式，没统一。
