## 这一版：退出家园不再「空白 + 整块弹回来」

**现象**：从家园返回，先空白几百毫秒，然后整页像被"弹"回原位（用户："页面整体弹到右下角才回归"）。

**查到的根因**（`teHomeLeave`）：

1. 旧代码**先把所有 `.pg` 的 `on` 摘掉、再加回上一页**，中间有一瞬间"没有任何页面是 on"；
2. 而 CSS 里有 `html:not(.jh-home-on) #jh-home{display:none}` —— 桌面 iframe 在这一瞬被隐藏；
3. 再显示时，那本 13 万行的桌面文档要**整块重新栅格化** → 空白几百毫秒 → 内容回来时整体错位一格再归位。

**改法（`round-7.86`）**：

- 返回时**先把上一页加回 `on`，再摘掉其它页**（顺序反转，永远不出现"无 on"的瞬间）；
- 同一帧把 `jh-home-on` 和页面状态对齐，不再等 800ms 的轮询；
- 给 `html` 挂 `.te-no-fx` **600ms**：这段时间内全局 `transition:none / animation:none`，
  把 opacity 淡入、页面入场动画这些"弹"感一起按住（只影响返回那一刻）；
- 返回后 `requestAnimationFrame` 里**只做一次** `__jhRelayout()`，不连锁重排。

实测（headless，430×932）：返回后连续采样 10 次（每 40ms），`#jh-home` 的 `display`
**始终是 block**（改前有一帧是 none），`.te-no-fx` 正常挂上。

```bash
python3 _mobile/patch/round-7.86/apply.py
python3 _mobile/patch/round-7.86/apply.py --revert
python3 _mobile/build.py --install
```
