### 1.1 锁死不转（7.34）
- 第一次点按 → `document.documentElement.requestFullscreen()` + `screen.orientation.lock('portrait')`；
- 锁不住就冻结竖屏尺寸、整块等比缩小（不重排）；只对手机短边 ≤560 生效，平板/桌面不受影响；
- `?nolock=1` 或 `localStorage['te-no-lock']='1'` 可关。

### 1.2 星露谷（7.35）
四个根因：① 游戏 canvas 画出来前没有提示（黑屏）② 全屏落在被旋转的 wrap 上，`:fullscreen` 把 transform 抹了 → 游戏一直跑在 430×860 竖视口 + 默认 1.5× → "人物太大" ③ 返回键被游戏自己的全屏顶掉 ④ `svClose ↔ __svCloseTop` 互相递归，退出要 10.6s。
修法：全屏改落在外壳文档、加载卡（body 上、不跟着旋转）、默认倍率按短边（手机 1×）、递归护栏、**同时只开一份游戏**（以前开了两份，434MB 贴图加载两遍、两个循环抢线程、隐藏那份还在放音乐）、退出发 `sv:pause` 真停音乐。
⚠️ **游戏本体 `星露谷/index.html` 也改了**，回滚要连它一起。

### 1.3 家园聊天小窗（7.36）
在 `shell.html` 的 `teHomeBridge`（不是 editor.html）：
- 右下角按钮：`💬` emoji → **勾线气泡 SVG**；标题栏/折叠/关闭/发送全换勾线图标；
- 尺寸按**视觉像素**给（S 270×330 / M 350×430 / L 440×560），再按宿主缩放比折回去（以前显示成 516×634）；
- 拖动：只挂 document 一层 + `touch-action:none` + 拖完/换尺寸/转屏都重新夹在屏幕内；位置存 `te_hq_pos3`。

### 1.4 P3 插图换不动（7.36）

  角落那行「换图」也是 none → 点了没反应。现在纸卡接手点击 + 右上角勾线 ⟳ + 换完 toast「已换图」。
- **相册三张（Us/Home/Always）**：原本没有换图入口，补了勾线 ⟳ + 720px 压缩存储（`te2_arch0/1/2`）。
