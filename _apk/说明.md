# 潮汐回响 APK（外壳说明）

## 为什么要有它
Android 11+ 里，从文件管理器点开 HTML，浏览器/WebView 拿到的是 `content://` 地址，
**读不到同目录的图片**（家园素材、贴纸全白）——这就是"画面一直加载中"的原因。
打成 APK 后素材直接在包内，不存在这个问题。

## 结构
- `assets/index.html` —— 由 `TidalEcho-最新版.html` 自动生成（构建时把
  `家园素材/` → `aset/home/`、`ai-chat-paper-assets/` → `aset/paper/`，中文目录名在包里换成 ASCII）
- `assets/aset/home/**`、`assets/aset/paper/**` —— 素材，构建时统一压到宽 ≤1280（124MB → 12MB）
- 外壳 `src/com/tidalecho/app/MainActivity.java`：WebView + 内部 https 域名 `https://app.local/`
  - 用 https origin 而不是 file://，否则 WebView 会禁用 IndexedDB，聊天图片存不住
  - `shouldInterceptRequest` 把 `https://app.local/**` 从 assets 里发出去，并按**文件头**给 MIME
    （素材压缩后后缀仍是 .png，里头其实是 webp/jpeg，类型给错图就不显示）
  - 已开：JS / DOM storage / IndexedDB / 文件选择器（导入备份用）/ 外部 http(s) 链接交给系统浏览器
  - logcat 标签：`TidalEcho`（排查：`adb logcat -s TidalEcho`）

## 重新构建
```bash
bash /tmp/apk/build.sh      # 依赖 JDK17 + android-34/android.jar + aapt/apksigner/zipalign + 系统 zip
```
构建环境在容器 `/tmp/apk/`（JDK 17.0.2 aarch64、android-34 平台包、Ubuntu 原生 aapt/apksigner/zipalign）。
改完 `TidalEcho-最新版.html` 后重跑即可，产物 `/tmp/apk/TidalEcho.apk`，
再复制到手机 `Download/WeiXin/潮汐回响-测试版.apk`。

> 注意：Google 官方 build-tools 只有 x86_64，这台手机容器是 aarch64 跑不了；
> 所以用了 Ubuntu 源的 aapt/apksigner/zipalign（原生 arm64）＋ build-tools 里的
> `lib/d8.jar`（纯 Java，用本地 JDK 跑）来 dex。

## 数据说明
APK 是**新 App**，存储独立：旧环境里的聊天记录 / 贴纸 / 家园布置 / 零花钱不会自动带过来。
迁移办法：旧环境「设置 → 导出备份」存一份 JSON → 新 App「设置 → 导入备份」选它。
